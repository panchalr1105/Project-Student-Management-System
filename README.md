# Student Management System 🧑‍🎓

## 📌 About the Project

The Student Management System is a beginner-friendly Python project developed using Object-Oriented Programming (OOP). It helps users manage student records through a simple menu-driven program.

## ✨ Features

* Add new student records
* Display all student records
* Search for a student using their roll number
* Exit the program
* Simple and easy-to-use menu

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Object-Oriented Programming (OOP)

## 📂 Project Structure

```text
Student-Management-System/
│
└── Student_Management_System.ipynb
```

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open Jupyter Notebook.
3. Open `Student_Management_System.ipynb`.
4. Run the code cell using `Shift + Enter`.
5. Select an option from the menu.
6. Enter the required student details.

## 💻 Example

```text
===== Student Management System =====
1. Add Student
2. Display All Students
3. Search Student
4. Exit

Enter your choice: 1
Enter student name: Rahul
Enter student marks: 85
Enter roll number: 101
Student added successfully!
```

## 📚 Concepts Used

## ⚠️ Limitations

Student records are stored temporarily in memory. They are not saved permanently when the program ends.
